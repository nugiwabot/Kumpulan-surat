# Arsip Surat: Mora Republic WIFI & Uswah Cell
**Entitas:** Mora Republic & Uswah Cell  
**Kode Produk:** `MR` / `WIFI` / `UC`  
**Domain:** Penyedia Layanan Internet (ISP / RT RW Net), Voucher WiFi Publik, Penjualan Router, & Agen Komunikasi

---

## 1. Struktur Subfolder
- `01_Surat_Keluar/` : Surat permohonan izin penarikan kabel fiber optik, permohonan izin pasang tiang ke RT/RW/Kelurahan.
- `02_Surat_Masuk/` : Surat izin dari warga, tagihan dari penyedia bandwidth upstream, dan korespondensi pelanggan.
- `03_Formulir_Berlangganan_Instalasi/` : Formulir pendaftaran pasang baru internet, form survei lokasi, dan SLA pelanggan.
- `04_Kerjasama_Vendor_ISP/` : Kontrak kerjasama bandwidth dengan upstream provider, sewa tiang, dan mitra teknisi.
- `05_Tanda_Terima_Perangkat/` : Berita acara serah terima modem/router ONT, mutasi perangkat jaringan, dan tanda terima retur.
- `06_Template_Dan_Kop/` : Kop surat Mora Republic dan format formulir pendaftaran pelanggan.

---

## 2. Format Penomoran Surat
```
[No_Urut]/[Divisi]/MR/WIFI/[Bulan_Romawi]/[Tahun]
```
Contoh:
- `001/OPS/MR/WIFI/IX/2026` (Surat Permohonan Izin Tarik Kabel Fiber Optik ke Ketua RW)
- `001/SLS/MR/WIFI/IX/2026` (Formulir Berlangganan Paket Internet Rumah)
