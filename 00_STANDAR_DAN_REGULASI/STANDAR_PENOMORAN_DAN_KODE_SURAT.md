## 1. Format Baku Penomoran Surat

Semua surat keluar, memo internal (IOM), perjanjian kerja sama (SPK), dan keputusan resmi wajib menggunakan format baku penomoran berikut:

```
[Nomor Urut 3 Digit] / [Kode Divisi] / [Kode Entitas] / [Kode Produk] / [Bulan Romawi] / [Tahun 4 Digit]
```

### Penjelasan Komponen:
1. **Nomor Urut (3 Digit):** Dimulai dari `001` setiap awal tahun kalender untuk masing-masing entitas dan produk (atau per buku register master).
2. **Kode Divisi:** Singkatan 3-4 huruf kapital yang menunjukkan departemen pembuat/pengirim surat.
3. **Kode Entitas (PT/Brand):** Singkatan badan usaha resmi atau brand pengampu.
4. **Kode Produk / Proyek:** Singkatan nama portofolio produk properti atau unit bisnis.
5. **Bulan Romawi:** Angka Romawi `I` s/d `XII` sesuai bulan penerbitan surat.
6. **Tahun (4 Digit):** Tahun penerbitan surat, contoh: `2026`.

## 4. Ketentuan Registrasi & Penomoran

1. **Anti-Duplikasi:** Setiap nomor yang keluar **wajib** dicatat ke dalam `REGISTER_NOMOR_SURAT.csv` dan database `tools/surat_registry.json`.
2. **Tidak Boleh Loncat Nomor:** Nomor urut diberikan secara berurutan sesuai kronologi waktu pembuatan.
3. **Pemberian Nomor Otomatis via AI:** Gunakan tool otomatis yang disediakan di folder `tools/`:
   ```bash
   python tools/letter_manager.py issue --product GREN --div MKT --title "Permohonan Izin Open Table" --recipient "Jatinangor Golf"
   ```
4. **Pemberian Nama File:** File surat digital yang disimpan di folder arsip wajib mengikuti format:
   `[Nomor_Urut]_[Divisi]_[Entitas]_[Produk]_[Bulan_Romawi]_[Tahun]_[Judul_Singkat].[ekstensi]`  
   Contoh: `003_MKT_KAB_EJ_III_2026_IOM_Voucher_Survey_Serentak_Elit_Jatinangor.docx`
