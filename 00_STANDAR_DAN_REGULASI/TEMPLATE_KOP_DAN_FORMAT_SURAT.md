# TEMPLATE KOP DAN PANDUAN FORMAT SURAT
**Pedoman Format Tata Letak, Tipografi, & Kerangka Baku Naskah Surat**

---

## 1. Standar Format Dokumen (Word / PDF)
- **Ukuran Kertas:** A4 (210 x 297 mm)
- **Margin:**
  - Atas: 2.0 cm (atau 3.5 cm jika menggunakan kertas kop cetak)
  - Bawah: 2.0 cm
  - Kiri: 2.5 cm
  - Kanan: 2.0 cm
- **Font Naskah:**
  - Font Resmi: Arial atau Calibri atau Georgia
  - Ukuran Judul: 14 pt, Bold
  - Ukuran Sub-Judul: 12 pt, Bold
  - Isi Surat: 11 pt, Regular (Spasi 1.15, Spasi paragraf 4 pt after)
  - Footer / Catatan Kaki: 9 pt, Italic

---

## 2. Kerangka Kop Surat Resmi
Kop surat resmi memuat:
1. **Logo Perusahaan / Proyek** di sisi kiri atas.
2. **Nama Badan Usaha / Brand** (Huruf Kapital, Bold, 14 pt).
3. **Alamat Kantor / Galeri Marketing, Kontak Telepon, Email, dan Website** (9 pt, Regular).
4. **Garis Pembatas Horizontal Ganda** (Garis tebal atas, garis tipis bawah).

*Catatan: File aset kop surat resolusi tinggi (PNG 300dpi) tersedia di folder `01_GREN_PROPERTYKOST/07_Template_Dan_Kop/`.*

## 3. Template Markdown / Draft Surat

### A. Template Surat Keluar Resmi (Permohonan / Kerjasama)

```markdown
[KOP SURAT PERUSAHAAN / PROYEK]
--------------------------------------------------------------------------------

Nomor   : [Nomor_Surat] (Contoh: 001/MKT/KAB/GREN/IX/2026)
Lampiran: [Jumlah Lampiran] (Contoh: 1 Berkas / -)
Perihal : [Perihal Surat] (Contoh: Permohonan Izin Open Table)

[Kota Penerbitan], [Tanggal Bulan Tahun]

Kepada Yth.
[Nama Penerima / Jabatan]
[Nama Instansi / Perusahaan]
di Tempat

Dengan hormat,

Sehubungan dengan [Latar Belakang / Maksud Surat], bersama surat ini kami dari [Nama Perusahaan / Unit Bisnis] bermaksud mengajukan [Permohonan / Penawaran / Pemberitahuan] terkait [Rincian Singkat Kegiatan / Kerjasama].

Adapun rincian kegiatan / penawaran tersebut adalah sebagai berikut:
- Kegiatan / Agenda : [Nama Kegiatan]
- Hari / Tanggal    : [Hari, Tanggal]
- Waktu             : [Pukul Pagi s/d Selesai]
- Lokasi            : [Tempat Kegiatan]
- Person In Charge  : [Nama PIC & Kontak WA]

Demikian surat ini kami sampaikan. Atas perhatian dan kerja sama yang baik dari Bapak/Ibu, kami ucapkan terima kasih.


Hormat kami,
[Nama Entitas / Perusahaan]


(Tanda Tangan & Cap Basah)


[Nama Pejabat / Pengirim]
[Jabatan Resmi]

Tembusan:
1. [Pihak Tembusan 1]
2. Arsip
```
