# Arsip Surat: GREN Propertykost Jatinangor
**Entitas Legal:** PT Kenzo Anatha Bumi (KAB)  
**Kode Produk:** `GREN` / `EJ` (Elit Jatinangor)  
**Segmen:** Commercial Student Housing / Rumah Kost 3 Lantai (Jatinangor, Sumedang)  
**Lokasi Proyek:** Kawasan Pendidikan Jatinangor (Dekat Kampus Unpad, ITB, IPDN, Ikopin)

---

## 1. Struktur Subfolder
- `01_Surat_Keluar/` : Surat permohonan eksternal (izin open table, penawaran sewa booth, permohonan kerjasama).
- `02_Surat_Masuk/` : Surat balasan dari instansi, dinas, manajemen gedung, atau vendor.
- `03_Internal_Office_Memo_IOM/` : Memo internal antar divisi (contoh: IOM Promo Survey Voucher Yogya).
- `04_Perizinan_Dan_Legalitas/` : Dokumen PBG, SHM, izin lingkungan, dan legalitas fisik gedung.
- `05_Administrasi_Konsumen/` : SKUP (Surat Konfirmasi Unit Pesanan), Surat Pemesanan, Form Pengajuan, dan Kwitansi Konsumen.
- `06_SPK_Dan_Kontrak/` : Surat Perjanjian Kerja dengan kontraktor, arsitek, interior, dan vendor operasional.
- `07_Template_Dan_Kop/` : Master kop surat A4 resmi (300 dpi) dan template formulir standar.

---

## 2. Format Penomoran Surat
```
[No_Urut]/[Divisi]/KAB/GREN/[Bulan_Romawi]/[Tahun]
```
Contoh:
- `001/MKT/KAB/GREN/VII/2026` (Surat Keluar Permohonan Open Table Golf Jatinangor)
- `003/MKT/KAB/EJ/III/2026` (IOM Promo Survey Serentak Elit Jatinangor)
