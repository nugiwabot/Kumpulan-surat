# Arsip Surat: Yanproland Corporate & Holding
**Entitas:** Yanproland Group (Holding Perusahaan)  
**Kode Produk:** `YPL` / `CORP`  
**Domain:** Tata Kelola Korporasi, Manajemen Direksi, Penganggaran Holding, HRD, & Markom Lintas Unit Bisnis

---

## 1. Struktur Subfolder
- `01_Surat_Keputusan_Direksi_SK/` : Surat Keputusan (SK) Direksi tentang pengangkatan jabatan, struktur organisasi, dan SOP holding.
- `02_Surat_Tugas_Dan_Kuasa/` : Surat tugas perjalanan dinas, penunjukan perwakilan, dan surat kuasa khusus.
- `03_Internal_Office_Memo_Holding/` : Memo lintas anak perusahaan (contoh: Pengajuan Anggaran Markom dan Sales Agustus 2026).
- `04_Legalitas_Holding/` : Akta pendirian holding, NIB, NPWP perusahaan, dan dokumen perizinan berusaha OSS.
- `05_Template_Dan_Kop/` : Master kop surat resmi holding Yanproland Group.

---

## 2. Format Penomoran Surat
```
[No_Urut]/[Divisi]/YPL/CORP/[Bulan_Romawi]/[Tahun]
```
Contoh:
- `001/DIR/YPL/CORP/IX/2026` (Surat Keputusan Direksi tentang Struktur Organisasi)
- `001/MKT/YPL/CORP/VIII/2026` (Proposal Pengajuan Aktivitas Markom dan Sales Holding)
