# Arsip Surat: Emeralda Kertajati
**Entitas Legal:** Yanproland / PT Siliwangi Anatha Bumi (SAB)  
**Kode Produk:** `EK` (atau `EKA`)  
**Segmen:** Aerocity Land Assets & Kawasan Terencana (Dekat Bandara Internasional Jawa Barat / BIJB Kertajati)  
**Portofolio Aset:** Lahan 1,4 Ha (20 Akta Jual Beli / AJB)

---

## 1. Struktur Subfolder
- `01_Surat_Keluar/` : Surat penawaran ke investor, surat permohonan ke dinas/pemkab Majalengka.
- `02_Surat_Masuk/` : Surat masuk dari calon investor, BPN Majalengka, dan perangkat desa Kertajati.
- `03_Internal_Office_Memo_IOM/` : Memo evaluasi appraisal aset tanah dan strategi divestasi/kerjasama.
- `04_Pertanahan_Dan_AJB/` : Dokumen administrasi 20 AJB, warkah tanah, dan surat riwayat tanah.
- `05_Penawaran_Investor/` : Proposal penawaran lahan aerocity, letter of intent (LOI), memorandum of understanding (MoU).
- `06_SPK_Dan_Legalitas/` : SPK notaris / PPAT, jasa appraisal, dan kuasa pengurusan perizinan.
- `07_Template_Dan_Kop/` : Template dokumen penawaran resmi Emeralda Kertajati.

---

## 2. Format Penomoran Surat
```
[No_Urut]/[Divisi]/SAB/EK/[Bulan_Romawi]/[Tahun]
```
Contoh:
- `001/LEG/SAB/EK/IX/2026` (Surat Keterangan Status Pertanahan AJB Kertajati)
- `001/MKT/SAB/EK/IX/2026` (Surat Penawaran Kerjasama Lahan Aerocity)
