# Arsip Surat: Hunian Asri Jatihandap
**Entitas Legal:** PT Siliwangi Anatha Bumi (SAB) / Yanproland  
**Kode Produk:** `HJA` (atau `HAJ`)  
**Segmen:** Perumahan Residensial & Kavling Tapak Siap Bangun  
**Lokasi Proyek:** Jatihandap, Cimenyan, Kabupaten Bandung

---

## 1. Struktur Subfolder
- `01_Surat_Keluar/` : Korespondensi keluar dengan BPN, aparat desa, perbankan, dan mitra sales.
- `02_Surat_Masuk/` : Surat masuk dari warga, instansi pemerintah daerah, dan kontraktor.
- `03_Internal_Office_Memo_IOM/` : Memo operasional lapangan, kebijakan harga kavling, dan promo sales.
- `04_Pertanahan_Dan_Perizinan/` : Berita acara ukur tanah, izin siteplan kavling, dokumen SHM induk & pecahan.
- `05_Administrasi_Konsumen/` : SKUP kavling/rumah, surat pesanan, konfirmasi pembayaran, dan kwitansi.
- `06_SPK_Dan_Kontrak/` : SPK pembangunan unit konsumen, pematangan lahan (*cut & fill*), dan infrastruktur jalan.
- `07_Template_Dan_Kop/` : Template kop surat dan formulir reservasi Hunian Asri Jatihandap.

---

## 2. Format Penomoran Surat
```
[No_Urut]/[Divisi]/SAB/HJA/[Bulan_Romawi]/[Tahun]
```
Contoh:
- `001/OPS/SAB/HJA/IX/2026` (Berita Acara Pengukuran Lahan)
- `001/SLS/SAB/HJA/IX/2026` (Surat Konfirmasi Pemesanan Unit)
